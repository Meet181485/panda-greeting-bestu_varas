PANDA BESTU VARAS WEBSITE

PERSONALIZE YOUR MEDIA:
1. Open the assets folder.
2. Add four photos named exactly:
   photo1.jpg, photo2.jpg, photo3.jpg, photo4.jpg
3. Add your video named exactly:
   our-video.mp4
4. Optional: add video-poster.jpg as the video thumbnail.
5. To edit the letter or shayari, open index.html in a text editor and find the relevant text.

PREVIEW ON LINUX MINT:
Open terminal in this folder and run:
  python3 -m http.server 8000
Then visit http://localhost:8000

PUBLISH:
Upload the complete extracted folder, including assets, to https://app.netlify.com/drop.
Test the public website on your phone before sharing. Google Fonts need internet access.
